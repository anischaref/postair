# 📱 GUIDE RAPIDE POSTAIR
## Pour les Utilisateurs Non-Techniciens

---

## 🚀 EN 5 MINUTES

### 1. **S'INSCRIRE**
```
Cliquez sur "S'Inscrire" → Remplissez le formulaire:
- Nom : Jean Dupont
- Email : jean@gmail.com  
- Mot de passe : MaisoN123!
→ Cliquez "S'Inscrire" ✓
```

### 2. **SE CONNECTER**
```
Allez à "Se Connecter" → Entrez:
- Email : jean@gmail.com
- Mot de passe : MaisoN123!
→ Cliquez "Se Connecter" ✓
```

### 3. **PUBLIER UN MESSAGE**
```
Zone en haut → Écrivez votre message (max 255 caractères)
→ Cliquez "Publier" ✓
```

### 4. **MODIFIER/SUPPRIMER**
```
Trouvez votre message → Cliquez "Modifier" ou "Supprimer"
(Vous ne pouvez que modifier/supprimer VOS messages)
```

### 5. **SE DÉCONNECTER**
```
Cliquez sur "Se Déconnecter" en haut → Vous êtes déconnecté ✓
```

---

## ⚠️ ERREURS COURANTES

| Erreur | Cause | Solution |
|--------|-------|----------|
| **Message vide** | Rien n'a été écrit | Tapez quelque chose |
| **255 caractères dépassés** | Texte trop long | Réduisez le texte |
| **Email incorrect** | Mauvais email/mot de passe | Vérifiez l'orthographe |
| **Email déjà utilisé** | Compte existant | Utilisez un autre email |
| **Permission refusée** | C'est pas votre message | Seuls vos messages peuvent être modifiés |

---

## 💡 CONSEILS IMPORTANTS

### ✅ À FAIRE
- ✍️ Soyez respectueux
- 📝 Soyez concis (max 255 caractères)
- 🔍 Relisez avant de publier
- 🔐 Mot de passe fort : majuscules + chiffres + symboles

### ❌ À ÉVITER
- 🚫 Spam ou messages répétés
- 🚫 Contenu offensant
- 🚫 Fausses informations
- 🚫 Messages vides

---

## 🔐 SÉCURITÉ

**MOT DE PASSE :**
- Minimum 8 caractères
- Incluez : Majuscules (A-Z), Minuscules (a-z), Chiffres (0-9)
- ❌ N'utilisez PAS votre prénom ou date de naissance
- ❌ Ne le partagez JAMAIS
- 🔄 Changez-le tous les 3-6 mois

**BON EXEMPLE :** PostAir2024$Secure!

## 🎯 FONCTIONNALITÉS PRINCIPALES

### 📝 Publier
- Écrivez dans la zone du haut
- Max 255 caractères
- Cliquez "Publier"

### 👀 Consulter
- Fil d'actualité avec 20 derniers messages
- Les plus récents d'abord
- Nom de l'auteur et date affichés

### ✏️ Modifier
- Trouvez votre message
- Cliquez "Modifier"
- Changez le contenu
- Cliquez "Mettre à jour"

### 🗑️ Supprimer
- Trouvez votre message
- Cliquez "Supprimer"
- ⚠️ DÉFINITIF et IRRÉVERSIBLE

## ❓ FAQ RAPIDE

**Q: Combien de messages je peux publier ?**
A: Autant que vous voulez !

**Q: Peut-on voir mes messages après suppression ?**
A: Non, suppression = disparu pour toujours

**Q: Je peux modifier un ancien message ?**
A: Oui, à n'importe quel moment

**Q: Qu'est-ce que "Se Souvenir de Moi" ?**
A: Reste connecté plus longtemps (ordinateur personnel uniquement)

**Q: Mes données sont sûres ?**
A: Oui, sécurisées par encryption

**Q: Je peux avoir 2 comptes ?**
A: Oui (2 emails différents), mais pas recommandé
