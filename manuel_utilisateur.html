📱À Propos de PostAir

PostAir est une plateforme simple et intuitive de partage de messages et de publications. Elle vous permet de :

  • 📝 Écrire et partager vos pensées en 255 caractères maximum
  • 👥 Lire les publications des autres utilisateurs
  • ✏️ Modifier vos propres messages
  • 🗑️ Supprimer les messages que vous avez publiés
  • 🔐 Gérer votre compte de manière sécurisée

⚡Démarrage Rapide

Première Visite

  1. Ouvrez votre navigateur web
  2. Allez sur la page d'accueil de PostAir
  3. Vous verrez deux options : Se Connecter ou S'Inscrire
💡 Conseil : Si c'est votre première fois, cliquez sur S'Inscrire. Si vous avez déjà un compte, cliquez sur Se Connecter.

📝Créer un Compte

Remplissez le Formulaire

📛 Nom d'Utilisateur

Entrez votre nom complet ou un pseudonyme. Ce nom sera visible par les autres utilisateurs.

Exemple : Jean Dupont, Marie93, TechLover_

📧 Adresse E-mail

Entrez une adresse e-mail valide et unique. Elle sera utilisée pour vous connecter.

Exemple : jean.dupont@gmail.com

🔐 Mot de Passe

Créez un mot de passe fort (minimum 8 caractères avec majuscules, minuscules et chiffres).

Exemple : MonPostAir2024!

🔐 Confirmer le Mot de Passe

Réécrivez le même mot de passe pour confirmation.

✅ Succès ! Si tout est correct, vous serez redirigé vers la page de connexion.

🔑Se Connecter

Entrez vos Identifiants

  1. Cliquez sur Se Connecter en haut à droite
  2. Entrez votre adresse e-mail
  3. Entrez votre mot de passe
  4. Cochez "Se Souvenir de Moi" (optionnel)
  5. Cliquez sur Se Connecter
⚠️ Important : Ne cochez "Se Souvenir de Moi" que sur vos appareils personnels.

🗺️Navigation Générale

Zone de Publication

La zone de publication se trouve en haut du fil d'actualité quand vous êtes connecté. Vous pouvez :

  • 📝 Écrire un message (max 255 caractères)
  • 🔢 Voir le compteur de caractères
  • 📤 Cliquer sur "Publier" pour partager

Fil d'Actualité

Le fil d'actualité affiche les publications de tous les utilisateurs, les plus récentes d'abord.

Pour chaque publication, vous verrez :

  • 👤 Nom de l'auteur
  • ⏰ Date et heure de publication
  • 📖 Contenu du message
  • 🔧 Boutons d'action (si c'est votre message)

✨Fonctionnalités Principales

1. Publier un Message

  1. Regardez la zone de publication en haut
  2. Cliquez dans le champ de texte
  3. Tapez votre message (max 255 caractères)
  4. Cliquez sur Publier
✅ Bon à savoir : Soyez concis, respectueux et relisez avant de publier !

2. Modifier un Message

  1. Trouvez votre message dans le fil
  2. Cliquez sur le bouton Modifier
  3. Modifiez le texte
  4. Cliquez sur Mettre à jour
💡 Info : Vous ne pouvez modifier que vos propres messages.

3. Supprimer un Message

  1. Trouvez votre message dans le fil
  2. Cliquez sur le bouton Supprimer
  3. Confirmez la suppression
⚠️ Attention ! La suppression est définitive et irréversible.

🔴Erreurs Courantes et Solutions

Erreur : "Vous ne pouvez pas soumettre un message vide"

Cause : Vous avez cliqué sur "Publier" sans rien écrire.

Solution : Écrivez quelque chose dans la zone de publication et réessayez.

Erreur : "Le message doit faire 255 caractères ou moins"

Cause : Votre message est trop long.

Solution : Réduisez la longueur en supprimant des mots. Regardez le compteur de caractères.

Erreur : "E-mail ou Mot de Passe Incorrect"

Cause : L'e-mail n'existe pas ou le mot de passe est faux.

Solutions :

  • Vérifiez l'orthographe de votre e-mail
  • Assurez-vous que Maj n'est pas activé
  • Vérifiez que vous utilisiez le bon mot de passe

Erreur : "Cet E-mail est Déjà Utilisé"

Cause : Cette adresse e-mail est déjà associée à un compte.

Solutions :

  • Utilisez une adresse e-mail différente
  • Ou connectez-vous avec ce compte existant

💡Conseils et Bonnes Pratiques

Pour de Bonnes Publications

✅ À Faire

  • Soyez respectueux
  • Soyez concis et clair
  • Soyez authentique
  • Relisez avant de publier
  • Utilisez l'humour avec modération
  • Posez des questions pour engager

❌ À Éviter

  • Le spam ou les messages répétés
  • Le contenu offensant ou haineux
  • La publicité excessive
  • Les fausses informations
  • Le harcèlement
  • Les messages vides ou sans sens

Pour la Sécurité

🛡️ Protégez votre Compte

  • Utilisez un mot de passe fort
  • Changez-le régulièrement
  • Ne le partagez jamais
  • Déconnectez-vous sur les ordinateurs publics
  • Gardez votre e-mail à jour

❓Questions Fréquemment Posées

Puis-je avoir plusieurs comptes ?

Techniquement oui (avec différentes adresses e-mail), mais ce n'est pas recommandé.

Combien de temps les messages restent-ils visibles ?

Indéfiniment ! À moins que vous ne les supprimiez ou que l'administrateur n'intervienne.

Puis-je récupérer un message supprimé ?

Non. La suppression est définitive et irréversible.

Puis-je modifier un ancien message ?

Oui ! Vous pouvez modifier n'importe lequel de vos messages à tout moment.

Que signifie "Se Souvenir de Moi" ?

Vous resterez connecté plus longtemps. À n'utiliser que sur vos appareils personnels.

Mon mot de passe a été oublié, que faire ?

Contactez le support ou cherchez un lien "Mot de passe oublié" sur la page de connexion.
