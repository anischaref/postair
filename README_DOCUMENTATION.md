## 📋 RÉSUMÉ ULTRA-RAPIDE

### Pour S'Inscrire
```
1. Cliquez "S'Inscrire"
2. Remplissez: Nom, Email, Mot de passe (8+ caractères)
3. Cliquez "S'Inscrire"
✅ Compte créé !
```

### Pour Se Connecter
```
1. Cliquez "Se Connecter"
2. Entrez: Email et mot de passe
3. Cliquez "Se Connecter"
✅ Connecté !
```

### Pour Publier un Message
```
1. Écrivez dans la zone "Quoi de neuf ?"
2. Max 255 caractères (compteur visible)
3. Cliquez "Publier"
✅ Message publié !
```

### Pour Modifier/Supprimer
```
1. Trouvez VOTRE message
2. Cliquez "Modifier" ou "Supprimer"
3. Confirmez
✅ Message modifié/supprimé !
```

## ⚠️ ERREURS COURANTES

| Problème | Solution |
|----------|----------|
| **Message vide** | Écrivez quelque chose |
| **255 caractères dépassés** | Réduisez le texte |
| **E-mail incorrect** | Vérifiez l'orthographe |
| **Email déjà utilisé** | Utilisez un autre email |
| **Pas de permission** | Seuls VOS messages peuvent être modifiés |

## 🔐 SÉCURITÉ ESSENTIELS

✅ **Bon mot de passe:** MaisoN123!
❌ **Mauvais mot de passe:** 123456 ou password

**À FAIRE:**
- ✅ Mot de passe fort (8+ caractères)
- ✅ Majuscules + minuscules + chiffres
- ✅ Ne jamais le partager
- ✅ Se déconnecter sur ordinateur public

**À ÉVITER:**
- ❌ Votre prénom ou date de naissance
- ❌ Même mot de passe partout
- ❌ Écrire le mot de passe
- ❌ "Se Souvenir de Moi" en public
