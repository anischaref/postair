## SCÉNARIO 1 : PREMIER JOUR - JEAN DUPONT

### Situation
Jean, 45 ans, découvre PostAir pour la première fois. Il n'est pas très à l'aise avec la technologie mais veut partager ses pensées.

### Étapes

**10h00 - Arrivée sur le site**
```
Jean ouvre son navigateur et va sur PostAir
Il voit deux boutons: "Se Connecter" et "S'Inscrire"
"Je n'ai jamais eu de compte, je clique S'Inscrire"
```

**10h05 - Remplissage du formulaire**
```
Nom: "Jean Dupont"
Email: "jean.dupont@gmail.com" 
Mot de passe: Il écrit "123456"
❌ ERREUR: Mot de passe trop faible

Il change: "JeanDupont2024!"
✅ Inscription réussie
```

**10h07 - Première connexion**
```
Il entre ses identifiants
Il voit un message: "Bienvenue Jean !"
Il arrive sur la page principale avec le fil d'actualité
"Wow ! Je vois les messages des autres utilisateurs !"
```

**10h10 - Premier message**
```
Il clique dans la zone "Quoi de neuf aujourd'hui ?"
Il écrit: "Salut à tous ! J'ai créé mon compte PostAir aujourd'hui ! 🎉"
Il voit le compteur: "72 / 255" ✅
Il clique "Publier"
```

**10h12 - Succès !**
```
Son message apparaît en haut du fil d'actualité
Immédiatement
Avec les boutons "Modifier" et "Supprimer"
Jean sourit: "C'est cool ! Tout fonctionne !"
```

### Ce que Jean a appris
✅ Comment s'inscrire
✅ Importance d'un bon mot de passe
✅ Comment publier son premier message
✅ Que les messages apparaissent immédiatement

## SCÉNARIO 2 : CORRECTION D'ERREUR - MARIE MARTIN

### Situation
Marie, 32 ans, a publié un message avec une faute d'orthographe. Elle remarque l'erreur et la corrige.

### Avant
```
Marie publie: "Bienvenue sur la meilleur plateforme !" 
❌ Faute: "meilleur" au lieu de "meilleure"
```

### Découverte de l'Erreur
```
10:30 - Marie relit son message
"Oh non ! J'ai écrit 'meilleur' au lieu de 'meilleure' !"
Elle voit le bouton "Modifier" sous son message
"Parfait, je vais corriger !"
```

### Modification
```
1. Clic sur "Modifier"
2. Elle voit sa zone d'édition avec le texte original
3. Elle change "meilleur" par "meilleure"
4. Nouveau texte: "Bienvenue sur la meilleure plateforme !"
5. Clic sur "Mettre à Jour"
```

### Résultat
```
✅ Message corrigé instantanément
Le fil d'actualité affiche la version corrigée
Personne ne voit l'ancienne version
Marie est satisfaite: "Bien, c'est vu et corrigé !"
```

### Ce que Marie a appris
✅ La modification est rapide et facile
✅ L'erreur est corrigée immédiatement
✅ Personne ne voit les anciennes versions
✅ Elle peut relire avant de publier à l'avenir

## SCÉNARIO 3 : MESSAGE À SUPPRIMER - PAUL LEONARD

### Situation
Paul a publié un message sans bien penser. Maintenant il le regrette et veut le supprimer.

### Avant
```
14:00 - Paul publie dans une mauvaise humeur:
"Je déteste les lundis ! 😤"
Il l'a publié avant de réfléchir
```

### Réalisation
```
14:05 - Paul relit son message
"Hmm, c'était pas très positif comme message..."
"Et si les collègues le voient ?"
"Je devrais le supprimer"
```

### Suppression
```
1. Il trouve son message: "Je déteste les lundis ! 😤"
2. Il clique sur "Supprimer"
3. Un message apparaît: "Êtes-vous sûr ? Cette action ne peut pas être annulée"
4. Il relit bien: "Oui, je suis sûr"
5. Il clique "Oui, Supprimer"
```

### Après
```
✅ Le message disparaît complètement
Le fil d'actualité ne le montre plus
14:07 - Paul publie un nouveau message positif:
"Finalement, c'est pas si mal les lundis ! On y va ensemble 😊"
```

### Ce que Paul a appris
⚠️ **TRÈS IMPORTANT**: La suppression est définitive
⚠️ Il faut réfléchir avant de publier
✅ On peut rectifier en supprimant et en publiant un nouveau message
✅ Mieux vaut prendre un moment avant de publier

## SCÉNARIO 4 : ASSISTANCE TECHNIQUE - ALEX CHEN

### Situation
Alex essaie de publier un message mais se heurte à une erreur. Il ne comprend pas ce qui se passe.

### Le Problème
```
Alex écrit un long message sur ses vacances
Il clique "Publier"
❌ ERREUR: "Le message doit faire 255 caractères ou moins"
```

### Confusion
```
Alex pense: "Mais 255 caractères, c'est long ! Combien j'ai écrit ?"
Il voit le compteur: "312 / 255"
"Ah... Je dois réduire de 57 caractères"
```

### Solution
```
1. Alex compte ses mots
2. Il supprime les détails inutiles
3. Il simplifie ses phrases
4. Nouveau compteur: "245 / 255" ✅

Avant:
"J'ai passé des vacances extraordinaires en Italie, 
c'était absolument magnifique et mémorable. J'ai visité 
Rome, Venise et Florence. J'ai goûté les meilleurs 
pâtes de ma vie et j'ai pris des centaines de photos."

Après:
"Vacances en Italie ! Rome, Venise, Florence. 
Pâtes délicieuses et souvenirs mémorables 📸"
```

### Succès
```
5. Il clique "Publier"
✅ Message publié avec succès !
Alex comprend maintenant: "Ah, je dois être plus concis"
```

### Ce qu'Alex a appris
✅ Le compteur de caractères est son ami
✅ Être concis rend le message plus lisible
✅ Moins c'est plus !
✅ Les erreurs ont toujours une solution

## SCÉNARIO 6 : SÉCURITÉ - THOMAS ROUGE

### Situation
Thomas crée un compte PostAir. Il veut éviter les problèmes de sécurité.

### Mauvaise Approche (❌ À ÉVITER)
```
Thomas choisit: "Thomas1980"
Pourquoi c'est mauvais:
- Thomas = son prénom (facile à deviner)
- 1980 = son année de naissance (publique)
- Simple et court

Thomas écrit le mot de passe sur un papier sur son bureau
Thomas l'utilise aussi pour Gmail, Facebook, Amazon
❌ TRÈS DANGEREUX !
```

### Bonne Approche (✅ À FAIRE)
```
Thomas pense à la sécurité
Il crée: "PostAir$2024Thomas!"
Pourquoi c'est bon:
- Long (19 caractères)
- Mélange: Majuscules (P, T), minuscules (ostar), chiffres (2024), symbole ($, !)
- Unique à PostAir
- Facile à mémoriser pour lui

Il ne l'écrit nulle part
Personne ne le connaît
Personne ne peut le deviner
```

### Utilisation Quotidienne
```
Jour 1: Thomas se connecte
"Se souvenir de Moi": Il ne coche PAS (il est au travail)

Jour 2: À la maison
"Se souvenir de Moi": Il coche ✓ (c'est son ordinateur)

Jour 3: Bibliothèque publique
"Se souvenir de Moi": Il ne coche PAS ❌
Il se déconnecte quand il part
```

### Sécurité à Long Terme
```
Tous les 6 mois, Thomas change son mot de passe
"PostAir$2024Thomas!" → "Thomas2025$PostAir!"

Si quelqu'un lui demande le mot de passe:
"Désolé, je ne le partage jamais" ✅

Si son compte est piraté:
Il le signale immédiatement au support
```

### Ce que Thomas a appris
✅ Mot de passe fort = protection
✅ Ne pas partager = sécurité
✅ Unique à chaque service = mieux
✅ Changer régulièrement = recommandé
✅ Déconnexion = importante sur ordi publics

## SCÉNARIO 8 : ACCIDENT - ACCÈS NON AUTORISÉ

### Situation
Ahmed a oublié de se déconnecter d'un ordinateur public. Quelqu'un d'autre accède à son compte.

### La Situation
```
15:00 - Ahmed utilise PostAir à la bibliothèque
Il se déconnecte... mais attend, non ! Il oublie !
Il part en oubliant de cliquer "Se Déconnecter"
```

### Malveillance
```
15:30 - Une personne malveillante s'assoit à l'ordinateur
Elle voit: Ahmed est toujours connecté !
Elle publie un message offensant avec le compte d'Ahmed:
"Je déteste tout le monde !!!"
Elle supprime certains messages d'Ahmed
Elle change son mot de passe
```

### Découverte
```
16:00 - Ahmed arrive à la maison
Il va sur PostAir
Il voit le message offensant avec SON nom
Il est choqué: "Je n'ai jamais écrit ça !"
Il essaie de se connecter: "Erreur de mot de passe"
Il réalise: "Mon compte a été piraté !"
```

### Action d'Urgence
```
Ahmed contacte immédiatement le support:
support@postair.com

Message:
"URGENT: Mon compte a été compromis à [bibliothèque]
- Message offensant publié sans mon consentement
- Mot de passe changé sans mon autorisation  
- Messages supprimés
- Email: ahmed@email.com
- Nom: Ahmed"

Le support réagit dans 2-4 heures:
1. Réinitialise son mot de passe
2. Supprime les messages offensants
3. Restore les messages supprimés si possible
4. Le conseil de sécurité
```

### Leçons
```
✅ TOUJOURS se déconnecter sur ordinateur public
✅ Vérifier le lien de déconnexion fonctionne
✅ Ne jamais cocher "Se souvenir de Moi" en public
✅ Contacter le support rapidement en cas de problème
✅ Changer son mot de passe après incident
```

## SCÉNARIO 9 : UTILISATION RÉGULIÈRE - PIERRE LECLERC

### Situation
Pierre utilise PostAir quotidiennement. Voici sa routine.

### Routine Quotidienne
```
MATIN (8h00):
- Pierre se connecte avant le travail
- Il lit les nouveaux messages (20 messages environ)
- Il publie: "Bon matin à tous ! 🌅"

MIDI (12h00):
- Pause déjeuner
- Il voit les réactions et nouveaux messages
- Il publie: "Bonne app-tite tout le monde !"

APRÈS-MIDI (17h00):
- Fin du travail
- Il se déconnecte de son ordinateur professionnel
- À la maison, il se reconnecte
- Il publie ses pensées de la journée

SOIR (21h00):
- Avant le lit, dernière vérification
- Il lit quelques messages du jour
- Il publie un message positif avant le dodo
- Il se déconnecte
```

### Gestion de ses Publications
```
LUNDI: "Courage, c'est lundi !" (83 char) ✅ Publié
MARDI: "Les mardis j'aime bien" (24 char) ✅ Publié
MERCREDI: "Moyen de semaine, dans le stretch !" (39 char)
          Il voit une petite faute: "moyen" → "On est"
          Il clique "Modifier"
          Nouveau: "On est à moyen de semaine, dans le stretch !"
          Il clique "Mettre à jour" ✅ Modifié

JEUDI: "Presque le weekend !" (21 char) ✅ Publié
VENDREDI: "Weekeeend ! 🎉" (18 char)
          Le soir il voit... c'est trop court et pas assez constructif
          Il clique "Supprimer" ✅ Supprimé
          Il publie à la place:
          "Fin de semaine ! Temps pour se reposer et 
           s'amuser avec la famille 👨‍👩‍👧"

SAMEDI/DIMANCHE: Moins actif, mais reste connecté
```

### Statistiques d'une Semaine
```
Messages publiés: 6
Messages modifiés: 1
Messages supprimés: 1
Messages lus: ~140
Temps total: ~30 minutes

Satisfaction: Élevée ✅
```

### Ce que Pierre a appris
✅ Routine positive et saine
✅ Écrire ce qu'il pense sans censure
✅ Corriger ses erreurs facilement
✅ Supprimer ce qui ne lui plaît pas
✅ Communauté agréable et bienveillante
